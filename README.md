**VibeShop** is a Java web application for live-music commerce, built as a team project for the University of Salerno. It has accounts, a catalogue, a cart, checkout, order history and an admin area. I was the team lead. The project is finished.

- Code: [`website-turbo-layout`](https://github.com/Denis7Kom/website-turbo-layout)
- Stack: Java, JSP, Servlets, DAO, SQL, HTML/CSS
- Security: the source contains `AuthFilter` and `AdminFilter`. Object-level authorisation (can user A open user B's order?) has not been audited yet.

**VibeShop** è un'applicazione web Java per scoprire concerti e artisti e acquistare merchandising, sviluppata come progetto di gruppo per l'Università di Salerno. Include account, catalogo, carrello, checkout, storico ordini e area amministrativa. Ero il team leader. Il progetto è concluso.
